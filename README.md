# Mastodon-4.1-Usability-Theme
CSS code to paste into the Advanced CSS field in order to improve usability.

This will fix the mystery meat navigation on mobile, make dark mode add true black in order to save battery on OLED screens, add some nice "acrylic" style backdrop filter effects, and move the "Publish" toolbar to the bottom of the screen on mobile so that a thumb can reach it while holding a phone.
